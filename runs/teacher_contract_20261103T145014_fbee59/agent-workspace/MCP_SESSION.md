# Session tools

Role: exploration. Observation profile: rgb-only.

Only RGB images and measured robot state are supplied; locate objects with [object-localization](.agents/skills/object-localization/SKILL.md).

Tools: `dexmate_gripper`, `dexmate_hold`, `dexmate_motion_execute`, `dexmate_motion_plan`, `dexmate_motion_preview`, `dexmate_motion_status`, `dexmate_motion_stop`, `dexmate_observe`, `dexmate_status`, `dexmate_step`, `dexmate_teacher_state`, `evaluate`, `finish`, `register`, `rehearse`, `start_episode`, `status`, `submit`. The live tool schemas give arguments and limits. `status` reports budgets, bundles and episode state; `dexmate_status` reports the live robot and episode.
