# Session tools

Role: exploration. Observation profile: rgb-only.

Only RGB images and measured robot state are supplied; locate objects with [object-localization](.agents/skills/object-localization/SKILL.md).

Tools: `dexmate_gripper`, `dexmate_hold`, `dexmate_observe`, `dexmate_status`, `dexmate_step`, `evaluate`, `finish`, `register`, `rehearse`, `start_episode`, `status`, `submit`. The live tool schemas give arguments and limits. `status` reports budgets, bundles and episode state; `dexmate_status` reports the live robot and episode.
